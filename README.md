# 🕌 Islamic World

**Your companion for a connected Islamic lifestyle.**

Islamic World is an Android application designed to bring essential Islamic resources and everyday religious tools together in one place.

Explore the Quran, listen to recitations, read authentic Islamic content, and access useful tools through a simple and user-friendly interface.

## ✨ Features

* 📖 **Holy Quran** — Read the Quran with an intuitive reading experience.
* 🎧 **Ayah-by-Ayah Audio** — Listen to Quranic recitation verse by verse.
* 📚 **Mushaf View** — Experience a traditional Quran page-reading layout.
* 🤲 **Duas** — Access Islamic supplications.
* 📜 **Hadith** — Explore Islamic Hadith content.
* 📘 **Tafsir** — Read Quranic explanations and commentary.
* 🕋 **Prayer Times** — Access prayer-time information.
* 🧭 **Qibla** — Find the direction of the Qibla.

*Feature availability and content may vary by app version.*
